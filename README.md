A collection of coursework, practice assignments, and learning resources completed during data analytics training with PW Skills. This repository brings together exercises in SQL, Python, statistics, and data visualization.

## Topics covered

- **SQL:** DDL and constraints, filtering, joins, aggregate functions, grouping, window functions, CTEs, and database normalization.
- **NumPy:** Arrays, data types, dimensions, indexing, slicing, reshaping, broadcasting, and numerical operations.
- **Statistics:** Descriptive statistics, sampling, confidence and hypothesis testing, t-tests, chi-square tests, and ANOVA.
- **Data visualization:** Charts and plots for exploring distributions, relationships, and categorical data.

## How to use

1. Browse the SQL scripts and PDF references for database exercises.
2. Open the Jupyter notebooks in Jupyter Notebook, JupyterLab, or Google Colab.
3. Install the Python libraries used by a notebook before running its cells. A typical starting point is:

   ```bash
   pip install numpy pandas matplotlib seaborn scipy plotly bokeh
   ```

4. For SQL exercises, load the relevant database/schema in a compatible SQL environment and adjust database-specific syntax where needed.
